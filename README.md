
# GateOfLight —— 光路逻辑沙盒 (Light-based Logic Sandbox)

一个用 pygame 编写的单机沙盒游戏：在近乎无限的可缩放网格上摆放光学元件，让激光束
在空间中传播、反射、分束、组合，从而用光拼出可运行的数字逻辑电路。

## 主要特性

- 近乎无限的可缩放网格世界（默认 10000 x 10000 格），支持平移与缩放。
- 增量空间索引：按元件类型维护坐标集合，光路追踪与视口绘制只扫描相关元件，避免全图遍历。
- 组合逻辑不动点求解 + 时序延迟元件，构成同步时序逻辑系统。
- 求解分帧摊销：把每刻的全量求解摊到多帧，抹平单帧帧率尖峰。
- 中英双语界面、多主题（深色 / 浅色 / 高对比）、自定义键位。
- 描边放置与擦除、撤销 / 重做、图章粘贴、存档 / 读档。

## 核心元件

元件类型定义于 `TOOL_TYPES`：

| 元件 | 类型 id | 功能 |
| --- | --- | --- |
| 墙体 | wall | 阻挡光线；被光照到时切换颜色，挡光功能不变 |
| 激光源 | laser | 沿朝向发出光束，可开关，等效 NOT 门 |
| 反射镜 | mirror | 按 "/" 或 "\" 朝向反射，使光束偏转 90 度 |
| 异或门 | xor_gate | 三入一出，奇数（1 或 3）束入射时从输出边发出 |
| 耦合器 | coupler | 光路交叉 / 合束的连通元件，等效 OR 门 |
| 光与门 | and_gate | 信号光与控制光同时点亮才导通，组合逻辑 AND |
| 锁存器 | latch | 带上升沿状态的记忆元件，1-bit 存储 |
| 延迟线 | delay_line | 注入光延迟 n 刻后放出，唯一的时序元件 |

## 求解模型

每个 tick 分两阶段推进：

1. `solve_tick()` 做组合逻辑不动点迭代：清态 -> 消化射线 -> AND 判定 -> 锁存上升沿 -> 灯灭锁定，
   直到光路状态收敛或被预算截断。
2. `_advance_delay_lines()` 统一推进延迟队列：延迟线在第 t 刻注入、第 t+n 刻放出，
   由此引入时序维度，构成同步时序逻辑。

光路追踪使用行列空间索引（`bisect`）一跳定位同一条光线上的下一个元件或世界边界，
把单束光传播成本从 O(光程格数) 降到 O(命中元件数 x log)。
`seen` 按 (命中格, 方向) 去重，防止镜面回路死循环。

## 环境与运行

依赖：

- Python 3.x
- pygame

运行：
打包.exe命令
```
pyinstaller -F -w -i GateOfLight.ico -n GateOfLight.exe --add-data "GateOfLight.ico:." --add-data "SourceHanSansSC.otf:." script.py
```

## 程序结构

代码自上而下分为以下功能区块（源码中原以分节横幅注释标出，去注释版已移除横幅注释，函数与类结构保持不变）：

常量与主题 / 键位系统 / 增量索引 / 元件图标绘制 / 光路几何 /
追踪与求解 / 场景渲染 / HUD / 编辑操作 / 相机 / 事件分发 /
存档读档 / 撤销重做 / 主菜单 / 教程 / 设置页 / 主循环

关键模块与函数：

- `TraceCtx`：单轮光路记账本（射线队列、命中集合、预算计数器）。
- `solve_tick` / `_solve_tick_iter`：组合逻辑不动点求解；后者为可分帧续跑的状态机。
- `_SolveJob` / `_drive_sliced_solve`：时序求解分帧摊销。
- `_advance_delay_lines`：刻末统一推进全部延迟队列。
- `_handle_*`：各类元件的光线处理逻辑，统一注册于 `ELEMENT_HANDLERS`。

## 存档与设置

存档与设置固定写入可执行文件（或脚本）同级的 `saves/` 目录：

- 存档：`saves/` 目录下按槽位保存（默认槽位 1，按 F1 保存、F2 读取）。
- 设置：`saves/settings.json`（主题、键位、语言、延迟预设等）。

若该目录不可写（如放进 Program Files），存档会直接失败并给出提示，
需将程序移动到可写位置。
