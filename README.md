
# GateOfLight —— 光路逻辑沙盒

> 用一束光，搭出一台会思考的电路。

**GateOfLight** 是一款基于 `pygame` 的单机沙盒游戏。你在一张近乎无限、可自由缩放平移的
网格上摆放光学元件，让激光束在空间中传播、反射、分束、组合——把抽象的逻辑门变成屏幕上
真实流动的亮线，亲手"点亮"一套可运行的数字逻辑电路。

## 玩什么

- **搭元件**：墙体、激光源、反射镜、分束器、耦合器、与门、锁存器、延迟线，共 8 类，拖拽即用。
- **看光跑**：激光实时求解光路，与门、锁存器、延迟线当场给出逻辑结果，亮灭一目了然。
- **组合 + 时序**：与门/锁存器是组合逻辑，延迟线引入"延迟 n 刻再放行"的时序维度，可以搭出真正的同步时序电路。
- **随时反悔**：全量撤销 / 重做、3 个存档槽、复制粘贴、暂停冻结时序。
- **边玩边学**：内置分节教程，从"光是直线传播"讲到时序逻辑。

## 元件速览

| 元件 | 作用 |
|------|------|
| Wall 墙体 | 阻挡光线 |
| Laser 激光源 | 沿朝向发出光束，可开关 |
| Mirror 反射镜 | 按 `/` 或 `\` 朝向改变光路方向 |
| Splitter 分束器 | 一束光分成透射 + 反射两路 |
| Coupler 耦合器 | 光路交叉 / 合束的连通元件 |
| AND Gate 光与门 | 信号光与控制光同时点亮才导通 |
| Latch 光锁存器 | 带上升沿状态的记忆元件（1-bit 存储） |
| Delay Line 延迟线 | 注入光延迟 n 刻后放出，引入时序 |

## 运行方式

```bash
pip install pygame
python 灵.txt        # 或将文件改名为 .py 后运行
```

程序固定 120 FPS 运行，窗口可缩放。

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name GateOfLight --icon=GateOfLight.ico 灵.txt
```

- `--onefile`：打成单个可执行文件；
- `--windowed`：运行时不弹黑色控制台窗口；
- `--icon`：指定 exe 图标（需 `.ico` 文件）。

> 存档与设置固定写入**可执行文件同级**的 `saves/` 目录，避免打包后因临时工作目录变化导致读写失败。

## 求解原理（简述）

每个时间刻度（tick）由 `solve_tick()` 做一轮**不动点迭代**收敛组合逻辑：

1. 清态 → 从光源 / 发光锁存器 / 延迟线种子出发消化全部射线；
2. 判定与门：只有信号光与控制光同时点亮才导通；
3. 处理锁存器上升沿，翻转其输出状态；
4. 灯灭锁定：若本刻无任何变化则判定收敛，退出迭代。

组合逻辑当场收敛后，再由 `_advance_delay_lines()` 统一推进延迟队列——延迟线在 t 刻注入、
第 t+n 刻放出，由此把纯组合电路扩展为同步时序电路。
